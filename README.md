# Информационная система проведения полевых экспериментов по записи голосовых сообщений

Веб-приложение, решающее задачу эффективного сбора данных, 
необходимых для дальнейших исследований. Собираемые данные хранятся в базе, 
которую без труда можно выкачать в необходимом формате для дальнейшей 
обработки. В приложении предусмотрена удобная запись аудио, что позволяет 
информантам не беспокоиться о поиске диктофона и последующей загрузке 
сделанной записи на сайт (хотя, такую возможность у них никто не отбирает).
